# Долговая яма

Маленькая браузерная игра про игровой автомат и растущий долг. Крути автомат с сеткой 5×3, собирай паттерны, копи монеты на кону и вноси их в долг, пока не кончились прокрутки. Всё время решаешь одно: **крутить ещё** — множитель растёт, но паттерн из 💀 может сжечь всё, что на кону, — или **забрать** кон, пока он цел.

**Играть онлайн:** https://lilcmetanka.github.io/dolgovaya-yama/

Учебный проект курса «Проектирование и разработка игровых приложений», практика №1 — gray-box прототип ([задание](./ASSIGNMENT_01.md)). TypeScript + Phaser 4 + Vite.

## Как играть

| Что сделать | Клавиша | Кнопка на экране |
|---|---|---|
| Крутить автомат | Пробел | «КРУТИТЬ» |
| Забрать кон в счёт долга | Enter | «ЗАБРАТЬ» |
| Начать заново после проигрыша | R или Пробел | «ЗАНОВО» |

Кнопки нажимаются и мышью, и пальцем.

1. Крути автомат: одинаковые символы, сложенные в паттерн (ряд, столбец, диагональ…), кладут монеты **на кон**. Паттерны и их множители — на панели справа.
2. Каждая прокрутка подряд поднимает множитель: ×1, ×2, ×3… Он всегда виден на кнопке «КРУТИТЬ».
3. «Забрать» вносит кон в долг, но множитель снова становится ×1.
4. Одиночные 💀 безопасны. Но если черепа сложились в паттерн, сгорает всё, что на кону, и множитель тоже сбрасывается.
5. Закрыл долг — начинается следующий раунд с долгом побольше. Не успел за 12 прокруток — ты в яме.

Счёт — сколько долгов закрыто. Рекорд запоминается в браузере.

## Правила

### Сетка и символы

Автомат — сетка 5×3: 5 столбцов и 3 ряда. В каждой из 15 клеток символ выпадает сам по себе: чем больше вес, тем чаще.

| Символ | Вес | Цена |
|---|---|---|
| 🍒 вишня | 30 | скрыта |
| 🍋 лимон | 25 | скрыта |
| 🔔 колокол | 18 | скрыта |
| 💎 алмаз | 13 | скрыта |
| 7 семёрка | 9 | скрыта |
| 💀 череп | 26 | — |

У каждого символа своя цена, но на экране её нет: редкие символы дороже, и игрок узнаёт цены по опыту (числа — в `src/game/rules.ts`). Черепов на экране в среднем около трёх.

### Паттерны

| Паттерн | Какие клетки | Множитель |
|---|---|---|
| Ряд из 3 | 3 одинаковых подряд в ряду | ×1 |
| Ряд из 4 | 4 подряд в ряду | ×2 |
| Ряд из 5 | весь ряд | ×3 |
| Столбец | весь столбец из 3 клеток | ×1 |
| Диагональ ↘ и ↗ | 3 клетки по диагонали | ×1 |
| Квадрат | квадрат 2×2 | ×2 |
| «V» и «Λ» | галочка из 5 клеток через всю сетку | ×4 |
| Джекпот | все 15 клеток | ×10 |

### Как считается прокрутка

1. Ищутся все паттерны — и из обычных символов, и из черепов. Паттерны могут пересекаться, и каждый считается отдельно (внутри «V» лежат ещё две диагонали).
2. В одном ряду считается только самый длинный отрезок: «ряд из 4» не считается ещё и «рядом из 3». Джекпот перекрывает всё остальное.
3. Нашёлся паттерн из 💀 — кон сгорает вместе с выигрышем этой прокрутки, множитель снова ×1.
4. Иначе выигрыш — сумма «цена символа × множитель паттерна» по всем паттернам. Он умножается на множитель серии и идёт на кон.

### Множитель, долг и раунды

- Множитель — номер прокрутки в серии: первая ×1, вторая подряд ×2, третья ×3… Растёт даже без выигрыша. Серию обрывают паттерн из 💀, «забрать» и новый раунд.
- В раунде 12 прокруток. «Забрать» бесплатно и прокрутку не тратит, но пустой кон забрать нельзя.
- Как только внесено не меньше долга — долг закрыт. Излишек идёт в следующий долг и, если его хватает, сразу закрывает и его. Оставшиеся прокрутки сгорают.
- Прокрутки кончились — кон забирается сам. Если и так не хватило на долг — конец игры.
- Долг растёт в 1,5 раза каждый раунд (с округлением до 10): 30, 50, 70, 100, 150, 230, 340…

## Что пока не сделано

- Игра переделывается в автомат в духе CloverPit — по шагам. Сделана сетка 5×3 с паттернами, а вид пока прежний: заголовок, панели и большие кнопки.
- Магазина пока нет: он вернётся предметами и амулетами.
- Нет звука, меню и настроек — игра стартует сразу.
- Графика нарисована кодом, без картинок: фигуры, текст и эмодзи. Если в системе нет шрифта эмодзи (бывает на Linux), символы видны как квадратики — их различает цвет фона.

## Как запустить

Нужен Node.js 22 LTS (или 20.19 и новее).

```bash
npm install
npm run dev        # локальный сервер, обычно http://localhost:5173/
npm run typecheck  # проверка типов
npm run build      # проверка типов и сборка в папку dist/
npm run preview    # посмотреть собранную версию
```

Публикация: при push в `main` или `master` GitHub Actions собирает игру и выкладывает её на GitHub Pages (`.github/workflows/deploy.yml`). Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**. Если что-то не запускается — [TROUBLESHOOTING.md](./TROUBLESHOOTING.md).
