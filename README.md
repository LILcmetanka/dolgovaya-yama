# Долговая яма

Маленькая браузерная игра про игровой автомат и растущий долг. Крути барабаны, копи монеты на кону и вноси их в долг, пока не кончились прокрутки. Всё время решаешь одно: **крутить ещё** — множитель растёт, но 💀 может сжечь всё, что на кону, — или **забрать** кон, пока он цел.

**Играть онлайн:** _ссылка появится после публикации на GitHub Pages_

Учебный проект курса «Проектирование и разработка игровых приложений», практика №1 — gray-box прототип ([задание](./ASSIGNMENT_01.md)). TypeScript + Phaser 4 + Vite.

## Как играть

| Что сделать | Клавиша | Кнопка на экране |
|---|---|---|
| Крутить барабаны | Пробел | «КРУТИТЬ» |
| Забрать кон в счёт долга | Enter | «ЗАБРАТЬ» |
| Начать заново после проигрыша | R или Пробел | «ЗАНОВО» |

Кнопки нажимаются и мышью, и пальцем.

1. Крути барабаны: совпадения кладут монеты **на кон**.
2. Каждая прокрутка подряд поднимает множитель: ×1, ×2, ×3… Он всегда виден на кнопке «КРУТИТЬ».
3. «Забрать» вносит кон в долг, но множитель снова становится ×1.
4. 💀 сжигает всё, что на кону, и тоже сбрасывает множитель.
5. Закрыл долг — начинается следующий раунд с долгом побольше. Не успел за 12 прокруток — ты в яме.

Счёт — сколько долгов закрыто. Рекорд запоминается в браузере.

## Правила

### Символы и выплаты

| Символ | Вес | Пара | Три |
|---|---|---|---|
| 🍒 вишня | 30 | 4 | 20 |
| 🍋 лимон | 25 | 6 | 30 |
| 🔔 колокол | 18 | 10 | 50 |
| 💎 алмаз | 10 | 20 | 100 |
| 7 семёрка | 5 | 40 | 400 |
| 💀 череп | 8 | кон сгорает | — |

На каждом из трёх барабанов символ выпадает независимо: чем больше вес, тем чаще.

### Как считается прокрутка (строго по порядку)

1. Есть хотя бы один 💀 — кон сгорает, множитель снова ×1.
2. Три одинаковых — выплата из колонки «Три».
3. Два одинаковых на любых местах — выплата из колонки «Пара».
4. Иначе выигрыша нет.

Выплата умножается на множитель и идёт на кон.

### Множитель, долг и раунды

- Множитель — номер прокрутки в серии: первая ×1, вторая подряд ×2, третья ×3… Растёт даже без выигрыша. Серию обрывают 💀, «забрать» и новый раунд.
- В раунде 12 прокруток. «Забрать» бесплатно и прокрутку не тратит, но пустой кон забрать нельзя.
- Как только внесено не меньше долга — долг закрыт. Излишек идёт в следующий долг и, если его хватает, сразу закрывает и его. Оставшиеся прокрутки сгорают.
- Прокрутки кончились — кон забирается сам. Если и так не хватило на долг — конец игры.
- Долг растёт в 1,5 раза каждый раунд (с округлением до 10): 30, 50, 70, 100, 150, 230, 340…

## Что пока не сделано

- Нет звука, меню и настроек — игра стартует сразу.
- Графика серая (gray-box): прямоугольники, текст и эмодзи. Если в системе нет шрифта эмодзи (бывает на Linux), символы видны как квадратики — их различает цвет фона.
- Нет усилений. Идея на потом: тратить переплату долга на усиления — например, +2 прокрутки, щит от одного 💀 или старт серии сразу с ×3.
- Баланс проверен только симуляцией, на живых игроках ещё не тестировался.

## Как запустить

Нужен Node.js 22 LTS (или 20.19 и новее).

```bash
npm install
npm run dev        # локальный сервер, обычно http://localhost:5173/
npm run typecheck  # проверка типов
npm run build      # проверка типов и сборка в папку dist/
npm run preview    # посмотреть собранную версию
```

Публикация: при push в `main` или `master` GitHub Actions собирает игру и выкладывает её на GitHub Pages (`.github/workflows/deploy.yml`). Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**. Если что-то не запускается — [TROUBLESHOOTING.md](./TROUBLESHOOTING.md).
